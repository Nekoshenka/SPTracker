# SPTracker — трекер подарков компаньонам в Genshin Impact

**SPTracker** — это десктопное приложение для отслеживания прогресса получения подарков от компаньонов в игре Genshin Impact. Оно помогает игрокам планировать, какие наборы мебели стоит создавать в первую очередь, чтобы получить максимальное количество подарков.

> **Важно:** Приложение **НЕ** взаимодействует с игрой напрямую — все данные вводятся вручную пользователем. Это безопасно и не нарушает правила игры.

---

## Что это и зачем

В игре существует механика подарков компаньонов: персонажи предпочитают определённые наборы мебели в Чайнике Безмятежности. Если пригласить персонажа в понравившийся набор, можно получить подарки: **20 Камней Истока** и **20 000 Моры** (и элементальный осколок, в SPTracker он не фиксируется).

**SPTracker** помогает:
- Отслеживать, какие подарки уже получены.
- Понимать, какие наборы стоит делать следующими, чтобы получить максимум наград.
- Планировать прогресс с учётом имеющихся персонажей.

Приложение **не читает память игры** и не требует доступа к аккаунту — все данные вводятся вручную.

## Основные функции

### Управление аккаунтами
- **Создание аккаунта** — выберите персонажей, которые есть у вас на аккаунте.
- **Редактирование аккаунта** — добавляйте или убирайте персонажей (при этом нельзя удалить персонажа, у которого уже есть внесённый прогресс).
- **Переключение между аккаунтами** — поддерживается несколько локальных аккаунтов (в папке `data/accounts`).

### Внесение прогресса
- **Выбор персонажа** и **набора** с удобным поиском по имени и иконками персонажей.
- Если персонаж предпочитает выбранный набор — прогресс сохраняется.
- Если выбранная комбинация уже записана — кнопка меняется на **«Удалить прогресс**.

### Статистика
- **Получено подарков** — количество полученных подарков.
- **Максимум из имеющихся персонажей** — сколько всего подарков можно получить на текущем аккаунте.
- **Абсолютный максимум** — сколько всего подарков можно получить в этой версии игры (версия игры определяется файлом `game_data_v*.json`, который содержит информацию про определённую версию).
- **Камни истока** и **Мора** — автоматический пересчёт (20 камней и 20 000 моры за подарок).
- **Процент выполнения** — текущий прогресс.

### Анализ наборов
- Упорядоченный список наборов по **ценности** (сколько подарков можно получить от имеющихся персонажей за этот набор).
- Наборы с уже полученными подарками выделяются зелёным цветом — они уже ранее фигурировали в прогрессе, что означает, что они имеются на аккаунте и могут быть использованы повторно.

### Светлая и тёмная тема
- Переключение между темами в главном меню (изначально выбрана тёмная тема).

### Поддержка двух языков
- Русский и английский интерфейс (изначально выбран английский язык).

## Как пользоваться

### Первый запуск
1. Скачайте и распакуйте архив с приложением.
2. Убедитесь, что папка `data/` с файлом версии лежит в одной папке с `SPTracker.exe`.
3. Запустите `SPTracker.exe`.

### Создание аккаунта
1. Нажмите **«Создание аккаунта»**.
2. Введите имя аккаунта (не обязательно писать ник из игры, это лишь отображаемое имя).
3. Отметьте галочками всех персонажей, которые есть у вас.
4. Нажмите **«Сохранить»**.

### Внесение прогресса
1. Выберите аккаунт в списке в левом верхнем углу.
2. Нажмите **«Прогресс»**.
3. Выберите персонажа или набор (в любом порядке).
4. Второе поле отфильтруется по результатам первого.
5. Нажмите **«Внести связку»** (или **«Удалить связку»**, если будет выбрана уже записанная комбинация).

### Просмотр статистики
1. Выберите аккаунт.
2. Нажмите **«Статистика»**.
3. Изучите таблицы с прогрессом и процентами.

### Анализ наборов
1. Выберите аккаунт.
2. Нажмите **«Анализ наборов»**.
3. Смотрите список наборов, отсортированный по убыванию ценности и учётом наличия наборов.

## Инструкция по сборке из исходников

### 1. Установите Python 3.11.9

### 2. Установите зависимости

Откройте командную строку в папке с проектом и выполните:

```bash
pip install PySide6 nuitka
```

### 3. Установите Visual Studio Build Tools

Скачайте Visual Studio Build Tools 2022 и установите компонент **«Разработка классических приложений на C++»**.

### 4. Сборка приложения

Выполните команду:

```bash
nuitka --standalone --windows-console-mode=disable --enable-plugin=pyside6 main.py
```

#### Дополнительный параметр:

| Параметр | Описание |
|----------|----------|
| `--windows-icon-from-ico=app_icon.ico` | Установить иконку для `.exe` |

#### Пример полной команды:

```bash
nuitka --standalone --windows-console-mode=disable --enable-plugin=pyside6 --windows-icon-from-ico=app_icon.ico main.py
```

### 5. Подготовка к распространению

После сборки папка `main.dist/` будет содержать готовое приложение. Добавьте в неё папку `data/` с необходимыми файлами

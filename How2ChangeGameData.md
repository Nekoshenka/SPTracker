## Создание и обновление файла базы данных игры

Приложение использует файл `game_data_v*.json` в папке `data/`. Этот файл содержит всю информацию о персонажах и наборах, которую вы можете обновлять самостоятельно при выходе новых обновлений игры.

---

### Структура файла

```json
{
  "version": "7.0",
  "characters": {
    "char_id": {
      "en": "Character Name (English)",
      "ru": "Имя персонажа (Русский)"
    }
  },
  "sets": {
    "set_id": {
      "en": "Set Name (English)",
      "ru": "Название набора (Русский)",
      "liked_by": ["char_id", "char_id"]
    }
  }
}
```

---

### Поля и их значение

| Поле | Описание |
|------|----------|
| `version` | Версия файла (формат: `X.Y`). Используется для сортировки — приложение автоматически загружает последнюю версию из всех таких файлов в папке `data`. |
| `characters` | Объект со всеми персонажами. Ключ — уникальный идентификатор персонажа (например, `amber`). |
| `characters[char_id].en` | Имя персонажа на английском языке. |
| `characters[char_id].ru` | Имя персонажа на русском языке. |
| `sets` | Объект со всеми наборами. Ключ — уникальный идентификатор набора (например, `i_mondstadt_3`, где `i` - indoor (комплект вне дома), `o` - outdoor (комплект в доме), далее регион комплекта и порядковый номер). |
| `sets[set_id].en` | Название набора на английском языке. |
| `sets[set_id].ru` | Название набора на русском языке. |
| `sets[set_id].liked_by` | Массив идентификаторов персонажей, которым нравится этот набор. |

---

### Как создать новый файл для новой версии игры

1. **Откройте** папку `data/`.
2. **Создайте** новый файл с именем `game_data_vX.Y.json`, где `X.Y` — новая версия (например, `game_data_v8.0.json`).
3. **Скопируйте** структуру из предыдущей версии или используйте шаблон ниже.
4. **Обновите** список персонажей и наборов в соответствии с актуальной версией игры.
5. **Сохраните** файл.

При следующем запуске приложение автоматически загрузит файл с самой новой версией (согласно числовому значению в имени), хоть и в самом файле есть поле с версией, но не забудьте и название файла тоже подписать этой версией, это **влияет** на работоспособность.

---

### ⚠️ Важные правила

1. **Имя файла** должно начинаться с `game_data_v` и заканчиваться на `.json`. Например: `game_data_v8.0.json`.
2. **Версия в имени** должна соответствовать полю `version` внутри файла. Например, для файла `game_data_v8.0.json` поле `version` должно быть `"8.0"`.
3. **Уникальные идентификаторы** персонажей и наборов должны быть уникальными внутри всего файла.
4. **Языки**: обязательно указывайте оба языка (`en` и `ru`), даже если какой-то из них ещё не переведён.
5. **Персонажи в `liked_by`** должны существовать в разделе `characters`.

---

### 🔧 Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Приложение не видит новый файл | Проверьте имя файла: должно быть `game_data_vX.Y.json` (обратите внимание на подчёркивание перед `v`) |
| Ошибка парсинга JSON | Проверьте файл на наличие лишних запятых, кавычек и скобок |
| Персонажи не отображаются | Убедитесь, что все идентификаторы в `liked_by` существуют в разделе `characters`. |
| Версия не обновилась | Убедитесь, что числовое значение в имени файла выше, чем у предыдущего (например, `8.0` > `7.0`). |
